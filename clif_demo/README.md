# clif_demo — bundled CLIF demo dataset

Synthetic CLIF tables (**no real patient data**) to try the kit: set `tables_path` in
`config/config.json` to this folder (see [`config/README.md`](../config/README.md)).

Source: the CLIF demo dataset distributed with
[clifpy](https://github.com/Common-Longitudinal-ICU-data-Format/clifpy).
